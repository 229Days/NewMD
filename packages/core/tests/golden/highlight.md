# Highlighting

A paragraph with ==highlighted text== in it.

You can ==combine **bold** and highlight==, or ==put `code` inside==.

Adjacent marks: ==one== then ==two== with plain text between.

The marker works inside a heading too: ==look here==.

An unmatched pair is ordinary text: 5 == 6, and == on its own stays as typed.

Emphasis next to a mark: *emphasis*==touching==*emphasis*.
